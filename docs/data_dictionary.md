# Data Dictionary

| Field | Meaning |
|---|---|
| order_id | Unique transaction identifier |
| order_date | Transaction date |
| customer_id | Customer identifier |
| segment | Enterprise / Mid-Market / SMB |
| region | Sales region |
| salesperson | Salesperson identifier |
| product_name | Product/service sold |
| category | Product family |
| units | Units sold |
| unit_price | Pre-discount unit price |
| discount_pct | Discount fraction |
| gross_sales | Units × unit price |
| net_sales | Sales after discount |
| cost | Estimated cost |
| gross_margin | Net sales - cost |
| order_status | Completed / Returned / Cancelled |
| allocated_target | Target allocated to the analytical slice |
