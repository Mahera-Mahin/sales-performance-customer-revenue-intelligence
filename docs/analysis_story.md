# Analytical Story

This portfolio dataset intentionally contains a measurable performance signal: 2025 softness in West-region Components and broader Central-region underperformance.

Recommended analytical flow:
1. Start with overall revenue and target attainment.
2. Identify regions below target.
3. Drill into the weakest region.
4. Break the variance by category/product.
5. Examine customer and order contribution.
6. Quantify the variance.
7. Recommend an action supported by evidence.

This is synthetic data. Conclusions apply only to this portfolio dataset and are not statements about Cummins.
